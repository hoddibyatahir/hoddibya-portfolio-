Files:
- index.html: your responsive one-page portfolio website.

Before publishing:
1. Open index.html in Chrome to preview it.
2. Replace the three sample portfolio panels with screenshots of your own drawings.
3. Add your LinkedIn profile URL and professional email/contact details if you want them public.
4. Check all experience details and dates for accuracy.

Free publishing:
You can publish this site free using GitHub Pages:
1. Create/sign in to a free account at https://github.com/
2. Create a new PUBLIC repository named hoddibya-portfolio.
3. Upload index.html to the repository root.
4. Open Settings → Pages → Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will show your public website URL after deployment.

Privacy:
Do not publish your home address, personal ID documents, private company drawings, or confidential project information.
